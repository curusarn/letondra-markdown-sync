Letondra Markdown Sync

Letondra Markdown Sync is a small personal Windows app that keeps chosen Google Drive folders in sync with local Markdown files used in Obsidian. Google Docs in those folders are exported as Markdown to the computer, and edits made locally are written back to the same Google Docs.

It is used by its owner only, for their own Google Drive. It has no server of its own.
